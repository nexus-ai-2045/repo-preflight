# 0.13.0 — repository 所有の依存選択と PRIVATE・媒体検査の更新

## 必要な検査を repository が定義する

手元と CI の test 選択を repository の policy に結び付けます。Python の実 import、明示ファイル参照、支持する動的 loader・CLI 呼出しから consumer をたどり、単なる変数名や文言の一致で無関係な test を広げません。未知の対応は停止し、全件 test へ自動で切り替えません。

`source_roots` / `test_roots` はディレクトリと個別ファイルを支持します。`mapped` は owner が完全な検査範囲を定義する component に使い、`supplement` は mode を上書きせず必須 test・check を加えます。変更版、選択 policy、selector の hash を照合し、暗黙の pytest fixture 影響や未対応の動的参照を未検証の成功にしません。

Node・SQL・TypeScript の汎用依存解析や、任意の Python 実行を完全に解析する機能ではありません。各利用先は検査 scope と実行環境を所有し、固定参照の更新を個別に行います。この release だけで既存利用先の pin は変わりません。

## PRIVATE 名義・媒体・依存の更新

- PRIVATE 送信の期待名義を構造化 commit 欄へ限定。公開時の名義検査、本文・媒体検査の境界は維持します。更新 push は未送信 commit を対象にします。
- MP4 の JPEG カバーを型付き metadata として検査。合成 MP4 の試験は実機 ffprobe から分離します。
- optional `media` / `test` の pypdf を 6.21.4 へ更新し、依存する内部実装の source hash も対応版へ更新します。

## 採用と公開範囲

GitHub の tag と Release を作る版です。PyPI・npm への配布、repository visibility の変更、利用先の自動 repin は含みません。必要な CI とレビューを確認して main へ統合した版を、既存の手動 release workflow で指定します。
