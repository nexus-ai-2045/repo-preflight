# 0.11.0 — 非公開素材のメタデータ検査と形式別検査の改善

非公開リポジトリへの今回の送信では、動画・画像のメタデータを原本のSHA-256・Git objectと対応付けて検査する選択肢を追加しました。既定のstrict検査は維持し、公開・releaseにはこの限定モードを使えません。映像や画像の内容のプライバシーを確認済みとは扱いません。

GIF拡張本文を固定版gitleaksへ接続し、不正な拡張ブロックは停止します。PowerShell単引用符の連結とPython代替解析の判定を修正しました。PDF・MP3・限定H264 MP4の形式別検査、依存関係の更新、ローカル検査入口も含みます。詳細は[変更履歴](../../CHANGELOG.md)を参照してください。

検査成功は公開・送信・マージの承認ではありません。Windowsを含む対応範囲と任意依存は[実行環境の説明](../runtime-support.md)で確認できます。

検出用正規表現とレビュー済み合成負例の区別、大きい文書の変更文脈検査も改善しました。[採用判断](../adr/0017-release-identity-regex-and-fixtures.md)と[比較の上限](../adr/0018-bounded-private-text-delta-edges.md)に保証範囲を記録しています。

## Pillowを利用する媒体機能の下限

coreのPython 3.9対応（text・標準PNG）は維持します。GIF・PSD、追加画像メタデータ、PDF画像検査はPython 3.11以上とPillow `>=13,<14`へ限定し、旧版・不明版では入力をデコードする前に拒否します。旧Pillow 11の互換宣言は削除します。環境の自動導入・変更は行いません。[ADR-0019](../adr/0019-pillow-media-runtime-floor.md)に採用理由と移行境界を記録しました。
