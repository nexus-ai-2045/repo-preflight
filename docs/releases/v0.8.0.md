# v0.8.0 — 公開版の再構成と検査の接続

> v0.8.0 のタグは作り直す前の旧リポにあり、このリポには無いため、タグを指すリンクは開けません。下のリンクは、このリポの最初の commit（v0.10.0、`44fdece`）の版を指します。v0.8.0 時点の中身とは違うことがあります。

## 主な変更

- 公開履歴を再構成し、全履歴の秘密情報・個人識別子・公開名義を検査する経路を確認しました。
- このrepo自身から既存の共通CIを呼び、全9項目0件の基準値でラチェットを実行します。GitHubでの必須チェック・main保護の適用状況は、別途確認が必要です。
- 初回pushの比較元がゼロの場合を、非shallow・単一root commitに限定して扱います。
- 起動確認は一時サンプルの合成policyで実行し、実運用の非公開設定と配布先のずれの検査を維持します。
- 依存検査ツールの原本wheelを同梱し、SHA-256・LICENSE・バイト列を保持します。通信なしでの正規インストールと改変拒否を検証します。
- 登録名義としての `REDACTED`、禁止メール、公開名義の照合を区別します。禁止メールの照合値と個人識別子のリストは非公開設定として管理します。
- Windowsの標準出力・パス表記、CRLFとLFのdigest照合、共通workflowの比較元を修正しました。

## 既存の導入先で行うこと

公開後の `v0.8.0` または公開main上の確定SHAへ、workflowと `preflight-ref` の両方をそろえて更新してください。以前のSHA・タグへの互換参照は保証しません。skillを利用する環境はcheckoutを更新し、既存の `install_runtime_skills.py` を再実行します。

CLIの検査だけならPython 3.11以降とGitが必要です。導入方法は [README](https://github.com/nexus-ai-2045/repo-preflight/blob/44fdece1634d4afb355639ad465375dca5e5c868/README.md)、CI接続は [公開コマンドと共通CIゲート](https://github.com/nexus-ai-2045/repo-preflight/blob/44fdece1634d4afb355639ad465375dca5e5c868/docs/publish-and-ci-gate.md)を参照してください。

## 確認した範囲と制約

本リリース準備前のmainで、Linux・macOSのPython 3.11/3.13、WindowsのPython 3.13、および共通プリフライト・文書整合性・ラチェットのGitHub CIが成功しました。今回の版情報・README・文書リンクも、関連するローカル検査で確認しました。公開対象の最終SHAでの検査結果は、リリース担当が公開前に照合します。

機械検査の合格は公開承認ではなく、秘密情報の完全な不存在や依存関係の脆弱性不存在を保証しません。skillの配置だけで全操作を拒否することも保証しません。強制停止には検査を呼ぶ入口と、失敗時に操作を中止する接続が必要です。
