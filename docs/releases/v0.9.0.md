# v0.9.0 — 画像と文章の検査を速く正確に、公開ガードの登録を安定化

## 主な変更

- **大きな文章の検査を速くしました。** Pythonとして読めない文章は、引用の直後に `+` が来る連結があるときだけ文字単位の回復解析を行います。全引用の走査は、文字列配列か、区切り（空白かエスケープ）が3つ以上ある引用があるときだけ行います。絞り込みが復元を取りこぼさないことは、乱数の種を固定した差分テストで毎回確かめます。
- **画像の誤検知を直しました。** PNG・JPEGの圧縮画素をコードとして解析しないようにし、文字metadata（PNGの文字chunk、JPEGのXMP）だけを個人識別子の検査へ渡します。構造不正・展開上限超過・依存不足は検査不能として止めます。JPEGには任意の追加依存 `images` が必要です。
- **名義検査のすり抜けと読み込み失敗を直しました。** 作者欄の区切り文字によるすり抜けを、共通の原本commit解析で防ぎます。同梱の名義検査moduleはファイルから直接読み込み、ランチャーの置き場所や古い配布に左右されません。
- **公開ガードのフックの登録を安定させました。** `publish_guard_hook.py --install` は、スキルの置き場所のようなリンク経由で実行したときもリンク先ではなくリンクのパスで登録し、POSIXではホーム配下を `${HOME}` で書きます。登録が古い場所を指していれば書き直し、重複した古い登録は消します。
- **信頼済みの非公開照合を追加しました（導入候補）。** bare Gitのデータだけを読んで登録済みの個人情報と名義を検査する入口と、composite actionを追加しました。専用GitHub Appの発行元を照合します。運用での有効化・必須チェック化は人間のレビュー後です。
- **CIを速くしました。** テストを `pytest-xdist` で並行に走らせ、テストの段の時間はLinux 158→60秒、macOS 346→113秒、Windows 823→219秒になりました。

細かな変更は [CHANGELOG](https://github.com/nexus-ai-2045/repo-preflight/blob/v0.9.0/CHANGELOG.md) を参照してください。

## 既存の導入先で行うこと

公開後の `v0.9.0` または公開main上の確定SHAへ、workflowと `preflight-ref` の両方をそろえて更新してください。skillを利用する環境はcheckoutを更新し、既存の `install_runtime_skills.py` を再実行します。公開ガードのフックを使う環境は、更新後に `python3 scripts/publish_guard_hook.py --install` を1回実行すると、古い登録が今の場所に書き直されます。JPEGを含むrepositoryを検査する場合は、追加依存 `images` を入れてください。

CLIの検査だけならPython 3.11以降とGitが必要です。導入方法は [README](https://github.com/nexus-ai-2045/repo-preflight/blob/v0.9.0/README.md)、CI接続は [公開コマンドと共通CIゲート](https://github.com/nexus-ai-2045/repo-preflight/blob/v0.9.0/docs/publish-and-ci-gate.md)を参照してください。

## 確認した範囲と制約

本リリース準備前のmainで、Linux・macOSのPython 3.11/3.13、WindowsのPython 3.13、および共通プリフライト・文書整合性・ラチェットのGitHub CIが成功しました。公開対象の最終SHAでの検査結果は、リリースの手順で照合します。

機械検査の合格は公開承認ではなく、秘密情報の完全な不存在や依存関係の脆弱性不存在を保証しません。skillの配置だけで全操作を拒否することも保証しません。強制停止には検査を呼ぶ入口と、失敗時に操作を中止する接続が必要です。
