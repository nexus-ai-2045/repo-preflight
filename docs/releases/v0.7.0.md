# v0.7.0 — 公開コマンド・共通CIゲート・ラチェット

## 主な変更

- **公開コマンド** `scripts/publish_gate.py` を追加しました。削除済みを含む全履歴の検査が `pass` で、手元と origin の全 ref が一致し、人が `--apply --confirm OWNER/NAME` を打ったときだけ公開へ切り替えます。既定は dry-run で、切り替え後に GitHub 上で `PUBLIC` になったことを確認します。
- **共通 CI ゲート** `.github/workflows/preflight-gate.yml` を追加しました。各リポジトリは `uses:` の1行で呼べ、`<job id> / preflight` を必須チェックにできます。
- **ラチェット** `scripts/preflight_ratchet.py` を追加しました。検査ごとの指摘件数を基準値ファイルと比べ、増加・PR での基準値の緩和・締め忘れを失敗にします。公開の判定には基準値を使いません。
- リリースは `.github/workflows/release.yml`（手動起動）で、版の整合を確かめてから tag と GitHub Release を作るようにしました。
- 持ち主の個人名義を実行環境から集めて照合する `scripts/local_identity_guard.py`、汎用の照合エンジン `scripts/identity_normalization.py`、名義・共同作者行の検査 `scripts/identity_gate.py`（報告のみ）を追加しました。

## 確認範囲と制約

GitHub の設定画面や `gh` を直接使った公開は止められません。公開は公開コマンドから行う運用で守ります。ラチェットは件数で比べるため、同じ検査の中で指摘が入れ替わっても気づけません。

導入手順は [公開コマンドと共通CIゲート](https://github.com/nexus-ai-2045/repo-preflight/blob/v0.7.0/docs/publish-and-ci-gate.md)、設計判断は [ADR-0009](https://github.com/nexus-ai-2045/repo-preflight/blob/v0.7.0/docs/adr/0009-publish-gate-and-ratchet.md)、詳細は[変更履歴](https://github.com/nexus-ai-2045/repo-preflight/blob/v0.7.0/CHANGELOG.md)を参照してください。
