# 0.14.0 — Gitフック管理と診断、検査とCIの整理

共有前の検査をGitフックへ接続し、不合格の種類と修正箇所を確認しやすくしました。READMEは、最短の検査、追加依存、AI連携、結果の読み方の順に整理しました。

## 主な変更

- Gitフックの導入前確認・状態確認・導入・更新・解除を追加しました。既存フックと設定を保持して呼び継ぎます。端末へ自動導入しません。
- 診断に検出種別、相対ファイル名、行、コミット、名義欄を追加しました。検出した秘密情報や個人識別子の実値を再掲しません。位置を取得できない場合は未確定とします。
- 手元とCIが同じrepository所有のテスト選択ポリシーを使います。CIで対応不明の変更を全件テストの成功に置き換えず、停止します。互換入口の`--run-selected-tests`には全件切り替えが残ります。
- CIのYAML内処理と`local_check.py`の依存解析を部品へ移しました。同じGit履歴の反復走査と、同一文字列への重複検索を減らし、検査範囲と失敗時の停止を維持しました。CI全体の安定した高速化率は確認できていません。
- 主要なCLI入口の通過・停止・終了コードを特性試験で固定しました。

## 依存と移行

- optionalのPDF依存をpypdf 7.0.0へ更新しました。PDF解析はPython 3.10以上が必要です。
- Pillowを使う画像・PDF画像検査にはPython 3.11以上とPillow `>=13,<14`が必要です。旧版・不明版・欠損は入力のデコード前に停止します。Python 3.9以降のテキスト・標準PNG検査は維持します。
- 非公開送信の名義検査とMP4内JPEGカバーの検査を更新しました。限定的なメタデータ検査は、画像・映像内容のプライバシーを保証しません。
- 廃止済みの`base-guard`を利用先で外す際は、独立workflow、固定参照、必須チェック設定を同じ変更単位で確認してください。

詳しい条件は[ランタイム対応](../runtime-support.md)、[Gitフック](../git-hooks.md)、[診断](../diagnostics.md)、[運用手順](../../OPERATIONS.md)、[変更履歴](../../CHANGELOG.md)を参照してください。

## 公開範囲

GitHubのタグとReleaseを作る版です。PyPI・npmへの配布、利用先の固定参照更新、フック導入、GitHub保護設定の変更は自動で行いません。検査成功は秘密情報や個人情報が無いことの保証ではなく、公開操作の承認とも別です。

今回の公開前検査に用いる、旧履歴の合成fixtureと登録済みbotトレーラーの限定承認は[再審査記録](v0.14.0-fixture-review.md)に記録しています。通常のcommit・pushの検査は維持します。
