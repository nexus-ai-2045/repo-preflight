# ADR-0002: 外部生成のPRセルフレビュー配布物を本文hashで検査する

- Status: Accepted
- Date: 2026-08-20
- Decision owners: repository maintainers

## Context

`CONTRIBUTING.md` の開発ルールは、実際のレビュー指摘から一般化された停止条件の
一部です。元になった一般化は複数リポジトリのレビュー指摘を横断で読んだもので、
正本はこのrepositoryの外、非公開側にあります。正本には出典PR番号と非公開
repository名が含まれるため、そのままは持ち込めません。

持ち込めるのは停止条件だけです。ただしコピーである以上、正本と食い違う劣化が
起きます。このrepositoryは正本も生成器も持たないので、通常のSSOT検査
（生成物を再生成して比較する）が使えません。

## Decision

移植版 `docs/pr-self-review.md` を生成物として受け入れ、次の性質だけを
このrepository側で検査します。

1. 文書は `| rules_version | <16桁hex> |` 行を1つ持つ。
2. `rules_version` は、`## R1 ` 見出し以降の本文をUTF-8でsha256した先頭16桁と一致する。

`documentation-contract` workflowの `PR self-review copy integrity` step が
これを検査します。読み取り失敗、行の欠落、見出しの欠落、不一致はすべて失敗で、
成功へ丸めません。

正本側は配布先ごとの `rules_version` を台帳で追跡し、正本を更新して再生成
していない状態を自分のCIで止めます。この2つを合わせて、片側だけが動いた
状態を両側から検出します。

## Alternatives considered

### 正本へのリンクだけを置く

採用しません。正本は非公開で、このrepositoryで作業する人もエージェントも
読めません。リンクは配布になりません。

### 停止条件をこのrepositoryで書き直す

採用しません。同じ事実が2箇所で別々に更新され、食い違いが検出されなくなります。

### 生成器をこのrepositoryへも複製する

採用しません。生成器は非公開の正本と出典データを入力に取ります。ここへ置くと、
動かせない実行ファイルと、正本側との二重管理が増えます。

### 検査せずコピーを置く

採用しません。手編集された配布物は、正本を読めない側からは正しく見えます。
本文hashの検査は、生成器なしで手編集を検出できる唯一の手段です。

## Consequences

- `docs/pr-self-review.md` は手で編集できません。内容の修正は正本側で行い、
  再生成した全文を持ち込みます。
- 検査するのは「配布物が改変されていないこと」だけです。正本側が正しいこと、
  配布物が最新の正本から生成されたことは、このrepositoryからは確認できません。
  後者は正本側の台帳が担当します。
- 外部runtime dependencyは追加しません。標準ライブラリだけで判定します。
- 配布物の`rules_version`の書式（`| rules_version | <16桁hex> |`）と、hash対象の
  開始位置（`## R1 ` 見出し）は、正本側の生成器と揃っている必要があります。
  どちらかが変わった場合は、このADRと検査stepを同時に見直します。

## Verification

少なくとも次を確認します。

- 未編集の配布物で step が通る。
- 本文へ1行追加すると step が失敗し、宣言値と実測値の両方を出力する。
- `rules_version` 行または `## R1 ` 見出しが無い文書は失敗する。
